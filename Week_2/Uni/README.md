# MATLAB Week 2 University Exercises

This README documents the contents and purpose of the `Uni` folder for Week 2 of the MATLAB coursework. The exercises focus on introductory image processing, image I/O, color space manipulation, and basic matrix operations using MATLAB.

---

## Directory Contents

The `Uni` directory is organized as follows:

- `Ch1_Import_save_img.m` &ndash; demonstrates importing images into MATLAB, displaying them, and saving in different formats.
- `Ch2_Grayscale_color_img.m` &ndash; converts color images to grayscale, extracts channels, and performs simple operations.
- `Ch3_Image_processing.m` &ndash; applies basic image processing tasks such as filtering and enhancement.
- `Ch4_Image_Type_Conversion.m` &ndash; covers conversion between image data types (e.g. `uint8`, `double`).
- `Ch5_Colorspace.m` &ndash; explores color space transformations (RGB, HSV, YCbCr, etc.).
- `Output/` &ndash; a folder to store images and figures generated by the scripts. Create it if it does not already exist.

---

## Tutorial Tasks

The university exercises are structured into a sequence of tasks similar to the classroom session but tailored for individual practice:

1. **Task 1: Image Import and Export**
   - Read images from files using `imread`.
   - Display images with `imshow` and `figure`.
   - Save modified images with `imwrite`.

2. **Task 2: Grayscale and Channel Operations**
   - Understand the matrix representation of color images.
   - Extract red, green, and blue channels.
   - Convert a color image to grayscale (`im2gray`) and analyze pixel intensity using `max`/`min`.

3. **Task 3: Basic Processing and Filtering**
   - Apply simple filters (e.g., `imfilter`, convolution) and enhancements to images.
   - Experiment with edge detection or contrast adjustments (as outlined in `Ch3_Image_processing.m`).

4. **Task 4: Data Type Conversion**
   - Convert images between `double`, `uint8`, and other types using functions like `im2double`.
   - Observe the effects on displayed intensity and arithmetic operations.

5. **Task 5: Color Space Exploration**
   - Transform images between RGB and other color spaces (HSV, YCbCr, etc.).
   - Visualize individual channels such as Hue or Luminance.
   - Review the detailed color space descriptions below for conceptual understanding.

## Color Space Details

A solid grasp of color spaces aids in tasks like segmentation, enhancement, and analysis. The scripts demonstrate these conversions; this section explains the concepts:

- **RGB (Red Green Blue)**:
  The most common representation for digital images. Each pixel stores three values corresponding to the intensities of red, green, and blue light. Useful for display, but operations like brightness adjustment affect all channels equally.

- **Grayscale**:
  Derived by averaging or weighted combination of the RGB components. Represented as a single channel where each value denotes intensity. Many algorithms reduce to grayscale to simplify computations.

- **HSV (Hue, Saturation, Value)**:
  Separates color information (hue), colorfulness (saturation), and brightness (value). Useful for color-based segmentation because hue is invariant to illumination changes. `rgb2hsv` and `hsv2rgb` perform the conversions.

- **YCbCr (Luminance, Chrominance)**:
  Common in video compression standards. Y contains luminance (brightness), while Cb and Cr contain blue-difference and red-difference chrominance components. Operations on Y affect perceived brightness without altering color.

- **Other spaces (e.g., Lab, CMYK)**: not covered by scripts but worth exploring for advanced applications; MATLAB provides functions like `rgb2lab`.

Each transformation is reversible (within quantization limits), allowing you to perform processing in one space and convert back to RGB for display or saving.

## How to Run the Scripts

1. Launch MATLAB and set the working directory:
   ```matlab
   cd('e:/Matlab/Week_2/Uni')
   ```
2. Execute any script by typing its name in the command window or by pressing **Run** in the editor (omit `.m`).
3. Examine figures that open or check the `Output` folder for saved images.
4. Modify parameters or add your own code to experiment. Comments inside each `.m` file offer guidance.
